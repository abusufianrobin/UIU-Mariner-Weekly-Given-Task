# 📊 Species Frequency Calculator

A simple and interactive web-based application to calculate species observation frequency and identify the most commonly observed species.

---


## 🎥 Demo Video

> Demo Video: https://github.com/user-attachments/assets/eb40a13e-caba-474b-950e-996cf1c5b0c5
---

## Features

- Add multiple species with observation counts  
- Automatically calculates total observations  
- Computes percentage frequency of each species  
- Identifies the most common species  
- Dynamic and responsive user interface  
- Copy results functionality  
- Clean and modern UI design  

---

## Application Overview

### Species Input Section
- Users can input species names and their observed counts  
- Displays how many species have been added (e.g., 4 / 10)  
- Includes:
  - ➕ Add Species  
  - ➖ Remove Last Entry  

### Frequency Results Section
- Displays:
  - Total Seen  
  - Number of Species  
  - Most Common Species  

### Results Table
- Species Name  
- Number Seen  
- Frequency (%)  
- Summary row with totals
